# Project Backend

Please read the [CONTRIBUTING.md](CONTRIBUTING.md) file before starting to work on this project.

## Prerequisites

- Node.js
- npm

## Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/2ING-PROJECT/backend.git
    ```
2.  Go to the project directory:
    ```bash
    cd backend
    ```
3.  Install the dependencies:
    ```bash
    npm install
    ```

## Configuration

1.  Create a `.env` file at the root of the project.
2.  Copy the content of `.env.example` into the `.env` file.
3.  Modify the environment variables in the `.env` file according to your setup.

## Running the project

To start the server in development mode with automatic reload, use the command:

```bash
npm start
```
